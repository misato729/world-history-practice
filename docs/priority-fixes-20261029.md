# 品質監査の優先4件の修正（2026年10月29日）

[品質監査](mock-quality-audit-20261029.md)で挙げた優先4件を修正し、通常ローカル開発DBへ反映した。対象は一般APIの出力と語句記述3問。公開環境への反映、コミット・push・デプロイは行っていない。

## 修正した内容

| 対象 | 修正 |
| --- | --- |
| 回答前の一般API | 入力条件を字種・固定字数・最大字数の許可リストから組み立て、管理用`hint`と未知の項目を返さない。DBと管理用の補足は保持。共通処理を使う取得・次問・履歴・お気に入りにも適用。 |
| 模試2・大問4・小問2（ID 60） | 原典根拠のある別表記を追加し、従来の表記も保持。 |
| 模試4・大問3・小問7（ID 116） | 定着した別表記と区切りの違いを有限の許容集合へ追加。全角等号の既存正規化も確認。 |
| 模試5・大問3・小問6（ID 146） | 説明の語をつなぐだけで名称を作れる旧問を、用語集の説明文に現れる人物の再生問題へ改稿。共有本文の森林利用・開墾という文脈を使い、下線(e)(f)を参照。関連する分類・解説・別名・出典を更新。 |

新問は提供版の用語集PDF通し66〜67頁の原画像と索引、名称に関する一次資料を確認し、作問者以外も照合した。修道会の頻度表示を人物自身へ転用していない。設問は修道会の創設と人物自身の活動を区別し、後続論述の主要解答を本文・解説・出典表示名に直接出していない。未提供版や実測難易度は確認済みとしない。

原稿V1・その検証記録を残し、森林と開墾の両方への参照を加えた最終V2を別ファイルに保存した。旧問固有の出典を差し替え、共通本文の根拠となる出典は保持した。原典・更新用データ・バックアップ・詳細な比較は[ローカル専用記録](../local-only/priority-fixes-20261029/result.md)に分けている。

## DB更新と保全

共通Writer・トランザクションから対象3問だけを更新した。公開状態と回答形式を変えず、内容版・ロック版は各1回増加した。問題150件・選択肢400件のID、他147問の全項目、全選択肢、セット・大問・本文、利用者・お気に入りを保持した。対象の分類リンク・参照行はWriterで作り直されるため、その行IDの不変は保証対象にしていない。

通常DBでは回答履歴が0件で、今回の削除も0件。独立した使い捨てDBでは、合成した対象3問の履歴だけが消え、対象外1問の履歴と4件のお気に入りが残ることを確認した。途中失敗のロールバックと再実行を検証し、再実行では更新0件・全16表の行内容が一致した。ロールバックの比較は行内容を対象とし、シーケンス値の巻き戻りを主張するものではない。

新問の主眼変更により文化史の実件数は64→65件（その他46→47件）、参照リンク150→151件、分類リンク406→407件となった。以前の監査・条件指定検証に記録した旧件数は、当時のスナップショットとして保持している。

## 確認したこと

- サーバー88件、フロントエンド368件の検査が成功し、型検査も成功。重い検査は順番に実行した。今回、全体ビルドは再実行していない。
- 実HTTPで公開150問を取得し、管理用`hint`が0件、入力条件が許可リストの範囲内、従来の正答用項目も回答前に隠れていることを確認した。
- 独立DBで25通りの許容表記・正規化入力、再送、旧内容版3件の拒否、対象外の旧送信の再利用、旧正答と誤答3件の不正解を確認した。
- 実際の通常開発APIとChromeで、PCから新問・別表記1問、スマートフォン表示（iPhone 16、393×852）から別表記1問・新問の別名を入力し、4回とも正解表示を確認した。管理用補足は表示されない。

既存の旧コピーファイル10件、前回の監査原稿・記録を保持した。[今回の変更ファイル一覧](../local-only/priority-fixes-20261029/files.md)に今回分と既存差分を区別して記載する。監査の個別改善19件、範囲・難度・資料判読の課題、合計得点画面は今回の修正範囲に含まない。
