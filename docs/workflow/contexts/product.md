# 商品・学習設計

更新基準日：2026年10月27日。ユーザーとの合意と[共通ルール](../../../AGENTS.md)を整理したものです。

## 目的

歴検1級・早慶等の難関大世界史を、限られた教材で効率的に学べるサービスにする。文化史・美術史の横断演習は、早稲田大学文学部・文化構想学部や美術検定対策も想定する。

## 正本と関連する文脈

- 学習・作問方針：[AGENTS.md](../../../AGENTS.md)。『詳説世界史』を主軸に、現行・旧課程の『世界史用語集』で細部を補う。
- サービス名・説明・試験構成・料金設定：[config/exam.json](../../../config/exam.json)。現在のサービス名は仮称「世界史ラボ」。
- 分類・テーマの運用：[classification.md](../../classification.md)。
- 根拠資料の受領・版の状態：[資料コンテキスト](sources.md)。過去問対応評価：[分析コンテキスト](audit.md)。

## 確定していること

- マニアックな用語の暗記量を増やすことを目的にせず、年代・地理・制度・因果関係と選択肢の正誤判断を支える。
- 学習者の必須参考書をむやみに増やさない。補助資料による内部検証と、学習者に示す主な出典を区別する。
- 予想問題は1大問7〜8小問、1セット4大問・合計30問（8・7・8・7問等）。大問内・選択肢間で時代と地域を横断し、単一王朝の連続史へ固定しない。共通の判断軸と全肢の根拠を保つ。詳細の正本はAGENTS.md。
- 語句記述は確認版用語集の①②又は見出し語ではない説明文内語句など、再生に難度のある対象を選ぶ。原画像の根拠と判断条件を確認する。頻度は採用教科書数であり実測難易度とは別に扱う。
- 正答語を知らなくても、確認済み知識による消去法で一意に正答できる場合は「解ける」と評価する。
- 章・節と文化史の指定を併用し、文化史内は美術史・音楽史・文学史・その他から主眼に応じて1区分を選ぶ。文化史全体と各区分で横断演習できる構成にする。
- 成人の歴検受験者だけでなく高校生も対象とし、クレジットカードの所持を前提にしない決済を検討する。

## 未決・次の作業

- 正式名称、価格、決済方法、運営者情報、公開先、販売開始時期は未確定。[現在の設定](../../../config/exam.json)では課金は無効。
- 新しい資料の受領時は、学習範囲と過去問対応を先に確認する。価格・決済・公開を決める際は、その時点の条件を調べて具体案を作る。
- 上記の未決事項はロードマップであり、課金有効化・決済契約・公開・購入を自動で行う許可ではない。

## 引き継ぎ時の注意

- 現在の1大問8小問を、4大問30問の全セットや全分野を網羅した商品として説明しない。
- 山川との対応評価を、作問者が直接参照した証明や毎年の合格保証へ読み替えない。
- 変更する場合は実問題の正本であるDBと、設定・検証用JSONの役割を分ける。実装の状態は[サービスコンテキスト](service.md)を確認する。
