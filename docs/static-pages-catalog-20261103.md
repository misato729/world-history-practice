# 静的ページでの問題API取得停止（2026-11-03）

## 原因と修正

共通サイドバーがトップ以外で無条件に `/api/v1/exams` を取得していた。取得を `/practice` とその配下、および最新資格確認後のトップ `/` に限定した。それ以外のページは、非ログイン・無料・購入済み・管理者・検証資格の全利用者について設定上の模試一覧を表示する。未知の静的ページと `/practice-guide` も取得対象へ入らない。

静的一覧では実公開の件数・大問・先頭番号を推測しない。無料/資格不明の6以降はロック付きプレミアム案内、既知の有資格者は演習開始ページへ送る。リンクの表示に使う既知の資格は認可の代わりではなく、演習開始後の資格/実データ確認を維持する。トップの資格確認より前にはカタログを取得しない。演習から静的ページへ移動した際は既存ローダーが進行中の取得を取り消し、遅延成功・失敗応答を破棄する。

対象は共有サイドバーの問題カタログ取得であり、ログイン・会員設定・決済設定・購入完了照合・履歴・お気に入りなど、各ページ自身に必要なAPIを停止する変更ではない。規約等の本文・問題DB・Stripe・本番設定は変更しない。既存の未コミット変更を保持し、コミット・push・デプロイは行っていない。
