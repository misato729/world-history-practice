# 問題演習の条件指定・件数表示（2026-10-28）

条件指定の「最大n問から条件で絞り込み」を、現在の条件で演習できる正確な「全n問」へ変更した。文化史はチェックボックスで複数選択できる。問題内容・配置・分類値は変更していない。実装・確認はローカル開発環境で行い、コミット・push・デプロイは今回の依頼に含めていない。

## 表示と条件の関係

- 章・節・文化史の条件を付けた公開問題一覧と、選択中の利用可能な模擬試験を照合して件数を出す。章・節と文化史はAND、文化史の複数区分はORとする。
- 「文化史全般に絞る」で美術史・音楽史・文学史・その他の文化史をまとめて選択・解除する。一部だけ選択したときは親チェックを部分選択で表示する。未選択は文化史で絞り込まない。
- 問題ごとの文化史分類は引き続き1区分。管理画面の分類入力も単一選択のままとする。
- 件数の確認中・取得失敗を0問として表示しない。取得失敗時は再試行でき、確認できるまで開始できない。確認済み0問は「全0問」と表示して開始を無効にする。模擬試験の未選択は選択を促す表示とし、0問と区別する。
- 開始直前にも同じ条件で一覧を再取得する。取得中に条件・選択模試・表示モード・認証状態が変わった場合、古い結果で開始しない。順次・ランダムの両方で文化史の複数条件を引き継ぐ。

## APIと非同期取得

既存の`history_topic=all`・`cultural_history`・各区分の単値URLを維持し、複数区分は`history_topic=art_history,music_history`のようなカンマ区切りに対応した。重複を除き、該当区分のいずれかに一致する問題を返す。章節・公開状態・利用資格の検査は共通の既存処理を通す。空の値、空要素、未知の区分、配列やオブジェクト、`all`等との混在は400とする。

条件タブの間だけ件数用一覧を取得する。条件・認証の変更を同期的に無効化し、要求世代と現在の条件の両方を検査する。取消を無視した遅延応答やA→B→Aの切替でも、古い成功・失敗を採用しない。トークンを要求キーや検証記録へ含めない。

| --- | ---: |
| 全150問・文化史未選択 | 150 |
| 文化史全般 | 64 |

- 実ブラウザのPC1440px・SP390px・320pxで選択・解除・部分選択・件数を確認した。音楽史を模試1だけに絞ると0問、模試2を加えると1問となる。模試未選択と0問で開始が無効になることも確認した。
- 美術史と音楽史の11問で順次演習「1 / 11」→次問「2 / 11」、SPでランダム演習「ランダム 1 / 11」を確認し、URL・条件表示の維持を確認した。SPの390px・320pxで横にはみ出さないことを確認した。
- 320pxで文化史全4区分64問から美術史を解除すると、残る3区分54問へ変わることも確認した。
- 遅延応答・取得失敗/再試行・同一描画内のA→B→A・認証変更・画面離脱の競合は合成応答の単体検査とコードレビューで確認した。実ブラウザで通信障害や会員切替を起こした検証とは区別する。
