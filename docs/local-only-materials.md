# ローカル専用資料と作業範囲

## 配置

作業の起点は、このリポジトリ `world-history-practice/` に統一します。親の「歴検世界史」フォルダはユーザー専用です。親フォルダへの資料探索、作業ファイルの作成、ファイル整理、以前の絶対パスへの自動フォールバックを行いません。

| 配置 | 用途 | リモートへの送信 |
| --- | --- | --- |
| `past-exam/` | 提供された過去問・解答の原資料 | 禁止 |
| `glossary.pdf`、`glossary*` | 用語集の原資料・今後追加する同系統の資料 | 禁止 |
| `詳説世界史.pdf`、各階層の`詳説世界史*` | 重要出典である教科書の原資料・複製・同接頭辞の画像/OCRフォルダ | 禁止 |
| `新課程用語.pdf`、各階層の`新課程用語*` | 新課程用語の原資料・複製・同接頭辞の画像/OCRフォルダ | 禁止 |
| `分析/` | 照合レポート、原本ページ画像、全文OCR、ローカル作業記録 | 禁止 |
| `local-only/` | 共通テンプレート由来のローカル専用資料置場 | 禁止 |
| `docs/classification.md` | 全19章・64節を含む分類の運用資料 | 追跡・送信対象外。ローカルとリモートmainの送信対象履歴から除去済み |
| `docs/workflow/` | 本文を含まない進捗・検証範囲・参照位置 | 通常の変更管理の対象 |

資料を `frontend/public/`、公開用素材、問題JSON、CIの成果物、Issue・PR添付、クラウドストレージ、外部サービスへコピーして禁止を迂回しません。ローカル専用資料が未配置の場合は資料待ちとして扱い、実装など独立した作業は続けられます。

## 送信を防ぐ仕組み

`docs/classification.md` は2026年10月27日の依頼で、手元の本文を保持してGitの追跡を解除し、Git・Dockerの除外と追加ポリシーを設定しました。`classification.md` というファイル名の接頭辞を追加保護するため、同名のバックアップも対象です。

同日の追加依頼で、除去作業時点の全9コミットと作業差分用tree参照を含む全6参照から同パスを除去しました。本文・分類設定・問題データ・既存作業差分を保持し、送信検査・pre-pushフック検査・pushのdry-runは成功。その後の明示承認により今回の変更をコミットし、確認済みの旧リモートOIDを指定した `--force-with-lease` でmainへ送信しました。実リモートの先端一致も確認済みです。別のcheckoutや旧参照から旧履歴を再取得した場合は、全参照の送信検査を再度行ってください。

復旧控えは `local-only/classification-history-purge-20261027/recovery.tar.gz` に保存しています。旧履歴・未コミット差分を含むため外部送信禁止です。通常のGit参照には復旧用の旧履歴を残していません。ローカルのreflog・到達不能objectの物理削除はしておらず、セキュア消去を実施したとの意味ではありません。詳細は[検証記録](verification.md)を参照してください。

- `.gitignore` で原資料と `分析/` を追跡対象から除外します。
- `.dockerignore` でDockerのビルド対象から除外します。リモートビルドへも渡しません。
- `.githooks/pre-push` が `scripts/check-private-sources.mjs --pre-push` を実行し、追跡対象と送信対象コミットの全親・マージ差分を含む全履歴を検査します。現在は削除されていても、過去のコミットに資料があれば送信を拒否します。
- 追加保護は`docs/workflow/policy.json`で設定し、根拠参照と送信検査が同じ判定を使います。設定を削除・変更しても、各階層の過去問・分析・`glossary*`・`詳説世界史*`・`新課程用語*`・歴検原資料PDF/ZIPの固定保護は解除しません。通常の接頭辞追加はファイル名に適用し、固定保護の`glossary*`・`詳説世界史*`・`新課程用語*`はディレクトリ名にも適用します。
- 設定とGit・Dockerの除外は別管理です。対象変更時は両方を更新します。
- CIでも全履歴を取得して同じ検査を行います。これは補助検査であり、push前の検査の代用にはしません。

新しく取得したリポジトリでは、push前に以下を設定します。すでに別のフック設定がある場合は上書きせず、既存の処理と整合させます。

```sh
git config --local core.hooksPath .githooks
node scripts/check-private-sources.mjs
```

`git add -f`、`git push --no-verify`、フックの無効化や別名への変更で保護を迂回しません。資料が追跡対象又は履歴に検出された場合はpushを止め、対象範囲を確認します。ファイルを作業ツリーから削除しただけで履歴から消えたと判断しません。履歴の改変・強制pushを無断で行いません。

## 移動後の参照

- 教科書の重要出典は `詳説世界史.pdf`、現行用語集は `glossary.pdf`、2025年問題は `past-exam/歴検1級世界史_2025.pdf`、従来の総点検の正本は `分析/2025用語集総点検/` です。教科書の版・課程と新たな照合範囲は[資料コンテキスト](workflow/contexts/sources.md)で区別します。
