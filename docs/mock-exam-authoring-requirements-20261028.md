更新日：2026年10月28日JST。対象は、今後作成・改稿する**4大問30問の模擬試験1セット**である。今回の依頼は過去問研究と要件の文書化であり、アプリ実装、既存180問の改稿・DB更新、コミット・pushは行わない。実装・登録の対応は利用枠復活後に延期する。

## 1. 最優先の合意と、この文書の読み方

「模擬試験1の大問1の体裁を引き継ぐ」は、**過去問の体裁と問題設計を踏襲する**という意味である。既存の自作大問1は、論述を省く当初の依頼に応じた大問1個の参考例であり、その回答形式・本数・設問順を4回複製するテンプレートではない。

- 模擬試験は4大問・合計30小問。1大問は7問又は8問。
- 選択20問、語句記述8問、論述2問。**論述は異なる2大問に1問ずつ配置する。** 同じ大問に2問をまとめない。残る2大問は論述なし。
- 本文の本数、長さ、下線、空欄、図表、設問との結び付きは大問テーマに合わせて設計する。全大問を単一の短い導入にそろえない。
- 下線は本文の実際の語句・文に付ける。(a)等の記号や参照リンクだけでは代用できない。

以降の「観察」は実物で確認したこと、「要件」はユーザーの指定を加えて今回の模試に採用する基準、「例」は成立する配分の一案である。これらを混同して、ある年度の形式・字数・配点を歴検の全年度共通仕様としない。

## 4. 本文・下線・空欄の要件

### 4.1 本文は出題の文脈を作る

- **LEAD-01**：大問の冒頭に共通テーマと読み方を示す。表示上の本文見出し、設問内の本文指定、参照ボタンは「【A】」「【B】」のように統一し、「本文A」「本文B」を表示名にしない（2026-10-28のユーザー指定）。複数本文にはA/B/C等の識別を付け、各本文が扱う事例・時代・地域を読み分けられるようにする。
- **LEAD-02**：本文に歴史的な状況、制度、出来事、人物の関係を叙述する。「交易、制度、文化、近代化などを考えよう」と論点名を列挙するだけの短文で、すべての設問への接続を済ませない。
- **LEAD-03**：単一本文、2事例の比較、多事例の短文群を選ぶ理由を設計票へ書く。複数本文を1つの文字列に結合したり、同じ文を見出しだけで分割したりして本数を満たさない。対応小問も本文ごとにまとめ、【A】の小問群→【B】の小問群→【C】の小問群の順で配置する。同じ大問の中で【A】→【B】→【A】と戻らない（2026-10-28のユーザー指定）。
- **LEAD-04**：本文A/Bで時代が大きく離れていてよい。共通テーマと比較・接続の軸は説明可能にする。単一時代・単一地域の縛りを自動的に加えない。
- **LEAD-05**：字数の一律固定は今回採用しない。設計票には実際の本文字数・段落数・本数を残し、参考紙面と説明密度を人が比較する。今回は原文全文の字数を実測していないため、本試験の標準字数を数値で断定しない。
- **LEAD-06**：時事リードでは現代の状況を歴史への入口にする。現代ニュースの暗記だけを30問の中心にせず、公表時点の数値・国境・所属の基準日を明示する。

### 4.2 下線を引く実際の範囲を指定する

- **REF-01**：今回の本文参照型の4大問には、設問につながる実体のある下線箇所を設ける。本文の語句・節・文を選び、始点と終点を確定する。語句だけでなく、制度や結果を述べた文を論述で説明させる方式も含める。
- **REF-02**：下線ラベル(a)等、下線を引く文字列、所属本文、参照する小問の対応表を作る。下線は本文の出現順に採番し、各本文内の設問も参照下線の(a)→(b)→(c)…のアルファベット順に配置する。同じ下線を共有する小問は連続させ相対順を保つ。本文全体参照は同じ本文の小問群内で内容に応じた位置を記録する。すべての下線参照が実在し、正しい語句・文の範囲に着地することを確認する。ラベルの付け替えだけで設問順の不整合を隠さない（2026-10-28のユーザー指定）。
- **REF-03**：`text: ""` の空アンカーや `underline: false` の参照記号だけでは下線要件に合格しない。太字、色、ジャンプボタンだけでも代用しない。通常表示に実際の下線が見えることを要する。
- **REF-04**：「下線部(a)に関連して」は、その箇所を足場に別時代・別地域へ展開できる。「下線部(a)の内容を説明せよ」は、当該箇所の内容を答える。呼び方と要求を使い分ける。
- **REF-05**：本文A/Bのラベルと、下線(a)/(b)、空欄(ア)/(イ)、地図上の地点a/bを混同しない。紙面上の記号が似る場合も、設問で所属・対象が判別できるようにする。
- **REF-06**：語句・文の空欄を本文又は設問内に置ける。空欄を選択式で答える場合も語句記述の場合もある。すべての空欄に対応設問を用意し、後続本文や別問に解答を露出させない。
- **REF-07**：全小問に無理に下線を付けない。空欄・本文A全体・図表から直接問う小問は、その参照対象を記録する。1つの下線を複数問で共有する場合は、異なる判断を問うことを確認する。

下線対応票の項目：`大問 / 本文ラベル / 下線ID・ラベル / 対象文字列と前後の短い識別情報 / 参照小問 / 問い方 / 出典照合先`。本文を編集したら対応票も再確認する。

## 5. 小問と選択肢の設計要件

| ID | 要件 |
| --- | --- |
| Q-01 | 正しい文・誤った文の選択、I/II正誤、語句/事項の組合せ、年代整序、本文空欄、地図・写真の判定などを組み合わせる。同じ形式・同じ長さの一問一答だけで20選択問を埋めない |
| Q-02 | 形式採用票には、少なくとも叙述正誤、I/II、年代整序、組合せ又は空欄、資料判読の配置を示す。件数は公式固定比率とせず、未採用の場合は理由と代わる判断内容を記録する |
| Q-03 | 単一選択は4肢・正答1件。設問の正/誤指定、正答ラベル、全肢解説をそろえる。並べ替え後に再点検する |
| Q-04 | 文章肢は、人物と著作、年代と制度、地名と政権、目的と結果などの対応を判断させる。すべてを名称だけの短い肢に単純化しない。一方、単語選択が適切な空欄問題まで不必要に長文化しない |
| Q-05 | 肢の間でも時代・地域を跨げる。共通する判断軸を保ち、設問の時代指定から外れるだけで捨てられる肢や無関係な固有名詞の並置を避ける |
| Q-06 | 一肢の中に複数時代の事実がある場合も、すべてを照合する。正しい語が一部にあるだけで肢全体を正答にしない |
| Q-07 | 誤答は人物・年代・地理・制度・因果等の誤りを特定できるものにする。「用語集にない」を誤りの根拠にしない。限定語・長さ・語調だけを手掛かりにしない |
| Q-08 | I/IIでは各文の正誤を独立に確認する。組合せの語句多数決や整序の列頻度だけで正答行が復元できないか確認する。正答位置の偏り・周期も点検する |
| Q-09 | 年代整序は対象事項・制度の制定/施行・国の成立等を特定する。年代が同じ又は諸説ある場合に一意の順を強制しない |
| Q-10 | 語句記述8問は、確認版用語集の①②、又は独立見出しでない説明文内語句等の再生に難度のある対象を選ぶ。頻度表示・見出し有無を原画像/索引で確認し、単にマニアックな語を増やさない |
| Q-11 | 語句記述は指定文字種・字数・別名・表記揺れを事前に決め、すべての許容正答が入力条件を満たすことを確認する。本文から写すだけの語句再生にしない |

2025年では、大問1問7は一国の複数世紀、大問2問1は遺跡・都市の地理、大問3問5は同時期の複数地域、大問4問4は近代の国と宗教施設の属性を組み合わせている。横断には複数の形があり、各肢が必ず異なる大陸である必要はない。

## 6. 論述2問の設計要件

- **ESS-01**：SET-03を満たす異なる2大問に各1問。既存の「論述なし大問」を模範とする場合も、このセット要件を落とさない。
- **ESS-02**：設問の文脈に適した位置へ置く。最終小問へ固定しない。2025年は2問とも問3、2011年大問1は問7である。
- **ESS-03**：出来事の過程・因果・比較・制度の内容・当事者の立場など、何を結び付けて説明するかを明示する。語句を並べるだけの問題を論述として数えない。
- **ESS-04**：字数上限、必須の観点、指定語がある場合の語群、字数の数え方を明記する。2025年の確認例は80字と60字である。今回の模試の初期案も同程度の短い論述2問から検討し、既存草案の140字等を本試験の標準として無条件に継承しない。異なる上限の採用時は要求要素と参考例との差を記録する。
- **ESS-05**：模範解答を実測し、字数・指定語・要求した主体/対象/関係/時期の充足を確認する。必要要素と許容する別表現を示す。問題・本文が模範解答を直接写せるものになっていないか確認する。
- **ESS-06**：配点3点×20選択＋3点×8語句＋8点×2論述＝100点はユーザー提示の参考案。公式配点としない。今回の旧年度解答解説冊子の目次下にも「選択20問×3点」「記述8問×3点」「記述2問×8点」・計100点の表記を確認した。表自体は後者を「論述」と呼び分けていない。適用年度の範囲、2025年への適用、公式性をこの表だけで確定しない。現行試験の公式配点を新たに確認したわけではない。
- **ESS-07**：非AIの要素別ルールは学習用の参考採点として別に点検する。本文・設問・模範解答を改稿した場合は、対象の版付きプロフィールの要素・指定語・字数・モデル・反例との対応も見直す。採点ルールに合わせて史実や設問を歪めない。未知表現を不正解と断定しない。
- **ESS-08**：2026年10月30日の合意により、参考配点は原則4要素×2点、3つの説明に自然にまとまる問題は3・3・2点で合計8点。各要素に複数の有限な許容表現を登録し、確認要素数と参考点を併記する。20字前後は設計の目安であり、要素別の入力制限にしない。一文で複数要素を満たせる。複合要素の一部だけを加点せず、否定・主体違い・語句列挙を反例で確認する。変更時は版を残して解説内の配点もそろえる。[実装と検証](essay-rule-scoring-20261028.md)を参照する。

論述の配置・問題としての成立と、採点機能の実装・精度は別の合格条件である。

## 7. 図表・地図・写真と表示の要件

- **VIS-01**：資料判読を含む大問をセット内に設計する。2025年の実物は統計図表・地図・建築写真を使っており、文字だけの設問へ一律に置換しない。全セットで同じ図版数を必須とする根拠までは確認していない。
- **VIS-02**：地図は年代・境界の基準、地点ラベル、凡例をそろえる。図と選択肢の位置・国・都市の対応まで確認する。写真は「写真の名称を知る」だけでなく、説明との対応を問う方式も選べる。
- **VIS-03**：図版は自作又は利用条件を確認したものを使う。過去問の図表・書籍画像をそのまま公開問題へ転用しない。代替テキストから正答が漏れないかも点検する。
- **VIS-04**：本文A/Bと各設問の所属を表示で読み分けられるようにする。過去問には本文→対応設問→次の本文という配置もある。Webでは本文と設問を縦並びにし、紙面の見開き2ページを2カラムUIとして複製する必要はない。
- **VIS-05**：PC/SPの実表示で下線の文字範囲、複数行への折り返し、下線ラベル、空欄、図版の可読性を確認する。HTML属性の存在、APIの成功、参照先への移動だけで体裁合格としない。
- **VIS-06**：同じ本文を使う小問間では本文を保持し、問題切替後はページ先頭へ戻す既存の合意を維持する。大問番号＋タイトルのh1、本文、設問の関係を確認する。

## 8. 原稿にそろえる成果物

1. **セット設計票**：大問別のテーマ・時事区分・本文本数/方式・問数・形式内訳・論述位置/字数・主な時代/地域・図版の計画。
2. **本文と小問の原稿**：本文A/B等、実際の下線範囲、空欄、図版、設問文、選択肢。対応関係を番号だけでなく内容でも読めるものにする。
3. **設問対応表**：各小問の参照本文/下線/空欄/図表、判断の中心、関連する時代/地域、正答、形式。
4. **解答・全肢解説**：正答理由と誤答箇所・正しい内容。語句の許容表記、論述のモデル・実測字数・必要要素を含む。
5. **出典照合票**：全肢・本文の事実・設問の手掛かり・解説の追加事実まで、確認した版/項目/ページ又は一次資料のURLに対応付ける。現在の学習分類と出典章節を混同しない。
6. **検査・体裁レビュー記録**：次節の項目ごとに結果、対象件数、確認日、担当を記録する。未確認は未確認のまま残す。

原画像・全文OCR・私的なページ照合記録はローカル専用とし、配信用の問題・解説や公開書誌へ原資料を丸ごと混ぜない。

## 9. 完成判定：数・内容・体裁を別々に確認する

| 検査 | 必須の確認内容 | 不合格例 |

| 小問 | 正答一意、指定正誤一致、全肢の訂正、形式の変化、横断の共通軸 | 長さ・語調・列の多数決だけで正答が決まる |
