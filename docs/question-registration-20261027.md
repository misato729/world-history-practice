# 横断大問8小問の登録（2026年10月27日）

ユーザーの「既存5問は捨てていいのでさっきの予想問題入れてください」という明示依頼により、通常のローカル問題DBの旧5問を、自作大問「知識と情報の記録・伝達」へ入れ替えた。

現在の登録は教材1・大問1・8小問（四択6問、語句記述2問）、選択肢24件。本文A/Bと(a)〜(h)の参照、全肢解説、書籍出典、主分類・関連分類を登録し、すべて公開状態にした。4大問30問の一式を収録済みとはしない。[演習](http://127.0.0.1:3200/practice/1/1)から利用できる。

## 原稿と出典の扱い

直前の横断設計稿を使用し、原稿のSHA-256と既存の前半・後半の原典照合記録が一致することを確認。今回の構造化では、本文・全8設問・24選択肢・8解説を独立担当が全文比較し、57項目すべて合格。問3は「徐光啓／徐光啟」・漢字3字、問6は「キープ」・カタカナとし、原稿にない字数制限を付けていない。

公開出典は山川出版社『世界史用語集』の確認済み電子版と確認項目。未確認の印刷ページやURLを作らず、PDF通しページ・原画像・端末内のパスはローカル照合記録だけに保持した。旧版・日本語『詳説世界史』・実測難度を今回確認済みとはしない。

## 入れ替えと保全

- 変更前のDBバックアップを権限0600でローカル専用領域に保存。
- 削除対象の旧5問ID・20選択肢と照合値を固定。利用者・履歴・お気に入り・決済・会員は各0件であることも確認。
- 合成テスト用5問を使う隔離DBで、照合不一致時の取消・正常入れ替え・反復時の無変更を先に検査して成功。通常DBの内容や秘密情報を検証DBへ複製していない。
- 共通Writerと単一トランザクションで旧5問だけを削除し、空になった問題領域へ明示的にv2アーカイブを取り込み。テーブル再作成や利用者作成はしていない。
- 保存後exportと、同じ操作を再実行したexportが、承認済み入力と全byte・全項目一致。独立担当も照合。再実行では問題・選択肢を作り直さず無変更で終了。
- 対象外の利用者・履歴・お気に入り・決済・会員件数を保持。旧5問のAPIは404。問題の自動再投入やcontent/questions.jsonの更新はしていない。

## 動作確認

- 実ローカルAPIで8問の本文・選択肢・解説・出典を比較し、全24選択肢を採点。正答6件・誤答18件が期待値と一致。
- 短答の徐光啓・徐光啟・キープが正答、別の語句は誤答、問6の漢字入力は条件エラー。回答前に正答・解説・出典を返さない。
- 主・関連分類と文化史のAND検索、文化史7問／非文化史1問、0件時に別問題を返さない動作を確認。
- 通常の画面でPC1440px、SP390px・320pxを実操作。選択式の採点と、異体字による問3、カタカナによる問6の採点・書籍出典を確認。横方向のはみ出しなし。
- 概要の収録件数、README、構成・カスタマイズ資料を実データへ更新。設定検査、原資料保護、差分検査も実施。

入力前のHTTP検査では、常にA/B両方が返るという期待値を修正した。実装は各小問が参照する本文だけを返すため、A又はBの1本文と正しいラベルを確認する。その後の一時的な503は設定表示の更新による開発サーバー再読込中の応答であり、再読込完了後の全検査は成功した。両記録を消さず保持している。

詳細な原稿・構造化入力・バックアップ・各検査と独立レビューは `local-only/cross-era-question-20261027/` と `local-only/cross-era-registration-20261027/` に保持し、GitやDockerのビルド対象へ含めない。
