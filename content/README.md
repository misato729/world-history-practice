# 体験用5問

`questions.json`には、世界史の知識を確認するために作成したオリジナル問題5問を収録しています。体験演習セット1として利用するデータで、歴史能力検定の公式過去問ではありません。本試験1回分の問題数や出題範囲を再現したものでもありません。

| セット・問 | 内容 | 選ぶもの | 正答 |
| --- | --- | --- | --- |
| 1・1 | 古代・中世の貨幣と交易 | 誤っている記述 | ②：ディナールは金貨 |
| 1・2 | 中国の貨幣・金融と交易 | 正しい記述 | ①：交子の成立と政府発行 |
| 1・3 | シャンパーニュの定期市とハンザ同盟 | 正しい正誤の組合せ | ②：Ⅰは正、Ⅱは誤 |
| 1・4 | 『集史』とモンゴル時代の使節・宣教師 | 正しい記述 | ①：ラシード＝アッディーンと『集史』 |
| 1・5 | 近世の陶磁器の生産と流通 | 誤っている記述 | ②：デルフトの製品は錫釉陶器 |

全問が四択・単一正答です。選択肢のラベルは①〜④で、各問に正答の説明と誤答部分の訂正を付けています。問題文、選択肢、解説は自作の文章です。

参照した文献・所蔵品解説は、各問の`source_text`に記録しています。『世界史用語集』の参照見出しを示す行のリンク先は、山川出版社の書籍案内です。案内ページが各見出しの解説本文を掲載していることを意味しません。

原資料のPDF本体や長文の転載は含めていません。個人のファイル名・保存先も問題データには含めていません。

問題ファイルの形式・安全な初期取込・既存DBの扱いは、[カスタマイズ手順](../docs/customization.md)を参照してください。

## 分類とテーマ

大分類は山川『世界史用語集』の章、小分類は節に対応します。横断的な問題は正答の判断に必要な知識を中心に主分類を1つ指定しています。第1問は第6章1節、第2問は第8章1節、第3問は第7章3節、第4問は第8章2節、第5問は第11章4節です。

第4問（『集史』・文化交流）は文化史、第5問（陶磁器）は文化史・美術史の両方です。美術史には工芸を含めています。判定は問題全体で問う知識に基づき、選択肢に作品名が登場するだけでは自動でフラグを付けません。[分類・テーマの運用](../docs/classification.md)を参照してください。
